# 信源核对

涉及进食问题或主张适用范围时，读 `skills/source-check/references/safety-and-evidence.md`。

## 先明确要支持的主张

一般做法/中国人群规范 → 国内相关指南或规范；方法效果与不确定性 → 相关系统综述及必要的原始研究；通俗解释 → 官方/专业机构公众材料；设备指标 → 对应型号技术资料与独立验证证据。用户偏好、时间安排和记录整理本身不强制查指南。

先按主题读取 `skills/source-check/references/source-registry.json` 对应条目。先查看 verification_status：仅 selected_sections_reviewed 的所列章节及 supported_claims 已做有限核对；候选或访问受限条目不能支持具体建议。记录含章节、核对日期和适用限制，不等于临床审核或永久有效。若知识库已挂接，可先用 search_knowledge 找相关段落与出处；仍须有支持本次主张的正文、人群和必要条件。

## 普通核对

1. 取得最相关资料的可读正文，确认标题、发布/制定机构、年份或版本、文档类型和支持主张的位置。一个来源足够就停止；多条不同主张确需不同资料时再补充。
2. 保留人群、地区、干预条件、例外和不确定性。机构权威性、研究证据确定性与对当前用户的适用性分别判断；不自创证据等级。
3. 官方公众材料可以支持对应层次的教育解释；不能自动支持精确数值、治疗决策或产品效果。设备厂商资料只支持其实际说明的定义和操作，不自动证明独立效果。

## 需要深入核对的情形

用户询问最新/替代/跨版本、精确数值/阈值、证据等级、特殊人群、疾病/药物相关条件或存在冲突时，进一步核对具体章节、表格脚注、版本关系及适用范围。无法取得完整条件时停止精确提取，提供已核对的一般解释或说明缺口。换个格式提问不会改变任务边界。

## 访问失败与预算

优先原始发布正文/附件 → 同发布者其他入口 → 官方完整转载 → 正式期刊版本。第三方完整副本需独立核对标题、机构、版本和可用的 DOI/文号；实际承载地址与原始出处分别记录。多个转载仍是同一份文献。

403/412/验证码/登录墙不重复请求同一地址，不绕过限制。普通问题通常一次定向搜索加一次抓取；整个回合最多三次搜索、三次正文抓取，失败和补链都计入。预算不足时返回已核对范围；综合研究超出预算，说明本轮不能完成系统性评估，不宣称已完成全面检索。

搜索摘要、新闻、营销文案、模型记忆不能替代正文。仅查到文件存在时只报告元数据；不要把“有这份指南”写成“已核验推荐”。正文、表格或适用条件缺失时不补写数字。

## 回答与留痕

面向用户给直接结论和必要条件，重要专业主张附近附一至两条真正支持该主张的链接。区分“原文建议”“用户自述”“计算结果”“助手提供的行动选项”。不输出所有检索日志。

用户明确要求保存研究笔记时，写到其指定文件，至少含 claim、source_id、title、issuer、version、canonical_url、retrieved_url、section_or_page、population、limitations、checked_at、verification_status。未要求时不自动保存个人资料或研究日志。新版本疑点须重新核对，不能把网页更新时间当文献版本。

完成条件：主张与实际读到的资料相符，适用条件与不确定性没有被省略；没有正文时诚实缩小结论。
